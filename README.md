
  # Modern Product Website UI

  This is a code bundle for Modern Product Website UI. The original project is available at https://www.figma.com/design/AgOcFvyeGhyOml2gkcz9Nn/Modern-Product-Website-UI.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

## Media URLs (Demo)
This project expects your media to be provided via Vite env vars:

- `VITE_DEMO_VIDEO_URL` - the URL to an `.mp4` (used by the demo video section)
- `VITE_SPLINE_URL` - the full `iframe` `src` URL for your Spline (clay) scene

See `env.example` and copy the values into your own `env` file as needed.
