# Maatriva Website AI Instructions

## Project Overview

Maatriva is a premium AI-powered healthcare website focused on modern UI, smooth animations, and excellent user experience.

## Before Writing Code

- Read the existing project first.
- Understand the architecture before making changes.
- Never create duplicate components.
- Reuse existing components whenever possible.
- Reuse existing animations.
- Keep the existing folder structure.
- Modify only the files needed for the requested feature.

## UI Guidelines

- Maintain a premium, modern design.
- Keep spacing and typography consistent.
- Ensure responsive layouts for mobile, tablet, and desktop.
- Preserve visual consistency across all pages.

## Animation Guidelines

- Reuse existing animation libraries if already installed.
- Prefer CSS or Framer Motion over adding new animation libraries.
- Keep animations smooth and avoid unnecessary effects.

## Code Quality

- Write clean, readable, production-ready code.
- Avoid duplicate logic.
- Remove dead code when appropriate.
- Explain any new dependency before adding it.

## Performance

- Minimize bundle size.
- Optimize images and assets.
- Avoid unnecessary re-renders.
- Keep pages fast to load.

## Accessibility

- Use semantic HTML.
- Ensure keyboard accessibility.
- Add appropriate ARIA attributes when needed.

## SEO

- Use proper heading hierarchy.
- Include descriptive meta information where relevant.
- Optimize page structure for search engines.
